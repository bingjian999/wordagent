## 安全修复验证总结

### 1. ShellTool 路径遍历防护 (HIGH — 已修复)

**漏洞**: ShellTool 的路径参数可通过绝对路径 (`/etc/passwd`) 或相对遍历 (`../../../etc/passwd`) 逃逸沙箱目录。

**修复方案**: 
- 在 `CommandRegistry.ArgSpec` 中新增 `isPath` 字段标记路径类型参数
- 在 `ShellTool.execute()` 中调用 `checkPathContainment()` 验证路径解析后仍在沙箱内
- 使用 `path.resolve(cwd, arg)` + `startsWith(cwd + sep)` 进行词法路径包含检查

**验证结果**: ✅ 23 项断言全部通过（7 个绝对路径 + 6 个遍历路径 + 2 个合法命令 + 3 个注入 + 5 个错误信息验证）

### 2. 无扩展名文件白名单绕过 (CRITICAL — 已修复)

**漏洞**: `AttachmentService` 的扩展名验证使用 `if (ext && ...)` 短路逻辑，当 `ext` 为空字符串时跳过白名单检查，允许无扩展名文件绕过限制。

**修复方案**: 修改为 `if (this.config.allowedExtensions.length > 0 && !this.config.allowedExtensions.includes(ext))`，确保空扩展名也被白名单检查覆盖。

**验证结果**: ✅ 11 项断言全部通过（拒绝 README + 拒绝 file. + 拒绝 script.exe + 接受 4 种白名单扩展名 + 空白名单接受 Makefile）
